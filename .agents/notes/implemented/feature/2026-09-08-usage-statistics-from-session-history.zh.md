# Agent Note: 从会话历史生成使用统计

Status: implemented

[English](2026-09-08-usage-statistics-from-session-history.md) | 中文

## 问题

用户需要在设置中查看跨会话活动与模型用量，包括已持久化和归档的对话。逐会话对话统计条无法回答整个数据目录中的每日或逐模型问题。将全部原始历史获取到浏览器会重复实现事件记账，并使统计依赖 UI 分页。

分叉继承、重试或中断的请求，以及本地日历日期，需要明确的统计拥有方。否则，复制的历史会倍增用量，失败请求会丢失已报告的 token，固定的当前 UTC 偏移量也会错误归类历史夏令时日期。

## 决策

[使用统计控制器](../../../../packages/api/usage-controller/README.zh.md)拥有 Host 聚合与独立的无 React Client 模型。其生成的 `usage.get` Remote 读取优先使用运行中会话的 `sessionQuery` 观察，无需附加智能体或传输原始历史。[Web 组合](../../../../packages/bundle/web-app/README.zh.md)选择四个并发读取和 256 个会话摘要缓存；必填的插件 Config 字段允许部署修改两个限制。缓存复用检查观察身份、序号或持久化修订号，以及时区。不设置持久分析索引。

精确总量复用官方 token-meter 归一化。每条已结算的 `assistant/message` 或 `assistant/attempt` 最多贡献一个来自最终消息用量或内嵌流的采样。最终用量即使无效也具有优先权；不完整计数记为缺失，不用更早采样替换。重试保持独立，失败或取消的尝试保留其已结算用量。已记录的压缩与子智能体用量计入 token，而活动仅由主会话用户消息产生。提供方/模型组合决定归属；排除继承事件时仍可使用继承的请求头。这保留了 [token 记账决策](../architecture/2026-07-29-projected-token-usage-and-request-context.zh.md)，同时不从其逐会话累计投影派生日历序列。

查看者提供当前 IANA 时区。Host 聚合应用该时区的历史规则，在所选 7/30 天范围中包含今天，并独立计算 365 个活动日期与不受范围限制的当前连续天数。未知或不完整用量不作估算，无法读取的会话产生明确的部分结果。无法枚举会话集合，或非空集合中的全部会话都无法读取时拒绝查询；空集合返回零统计。

[使用统计页](../../../../packages/client/ui-usage/README.zh.md)在 Web 与桌面端共享一个设置贡献。六张卡片、热力图、每日柱状图和模型环图通过 Slots 读取控制器的可观察源。首次加载之后，打开页面、选择范围、手动刷新和连接恢复都会查询。被替代的读取会取消；失败保留最近一次结果并明确标识过期状态。控制器在卸载时等待未完成工作结束。主题 token、本地化词典、键盘导航和无障碍文本使展示职责保留在 UI 包中。

## 考虑过的替代方案

**在浏览器中聚合历史。** 跨会话原始日志传输会暴露不必要的对话数据，在展示代码中重复实现事件语义，并使完整性依赖分页。

**维护持久的全局计数器或分析索引。** 当前没有消费方需要足以证明新增持久化格式、写入生命周期和恢复路径合理的后台新鲜度或查询延迟。有界内存摘要减少重复读取，同时保持会话日志的权威性。

**只聚合 `sessionStats` 与 `token-meter` 投影。** 它们的逐会话总量缺少页面所需的日历日期和逐模型信息。扩展这些投影会增加回填和保留状态，而仍然需要检查每个会话。

**统计所有继承的分叉事件。** 复制的前缀既不是新用户操作，也不是另一次提供方请求。排除继承事件可以避免多层分叉中的倍增；源历史被删除时会明确接受少算，因为没有跨会话事件身份可支持安全的回退去重。

**使用最终 assistant 消息和当前固定 UTC 偏移量。** 只统计最终消息会丢失失败或取消请求已报告的用量，一个固定偏移量无法表示历史夏令时变化。请求头与有效采样无需成功的最终消息即可提供记录的归属；IANA 时区无需存储用户旅行历史即可提供历史日期规则。

## 后果

该功能不更改会话事件或持久化格式，不创建模型输入或提供方请求。缓存未命中时，工作量与检查的日志规模成正比，因此大量历史可能延迟页面展示；缓存限制保留的会话数量，而非单个历史的长度。每个观察内部一致，但合并结果不构成跨全部会话的事务。删除历史会改变统计，没有已记录用量的辅助调用不计入精确总量，也不计入缺失尝试数量。

聚焦的聚合测试覆盖精确总量、重试、不完整用量、压缩、子会话不计活动、继承历史、日历日期和连续天数。Client 测试覆盖惰性读取、过期结果抑制、时区刷新、失败保留、重连、订阅者异常隔离和静默卸载。[仓库测试策略](../../../../docs/testing.zh.md)还要求组装后的 Web 证据；单元测试结果本身不能证明浏览器或真实模型行为。
